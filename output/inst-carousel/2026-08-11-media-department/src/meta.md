# Exact visible text

1. Как устроен медиа-отдел / Не чат с картинками. Фабрика: запрос → правила → skill → файлы, которые можно запостить.
2. Сначала brief, потом генерация / Пока не ясны тема, формат, язык текста и критерий готовности — агент не собирает слайды.
3. Skill держит процесс / Тема + design.md · HTML в src/ · Агентский export
4. В корне — только картинки для поста / Deliverable slide-01.png · Исходники src/ · HTML — производство. Instagram забирает PNG.
5. Понравилось? Упакуй в skill / Эксперимент → повтор → skill. Review → правки → re-export.
