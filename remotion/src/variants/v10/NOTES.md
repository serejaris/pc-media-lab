# V10 «Editorial / magazine serif revival»

## Research 2025–2026 (итог)

- Возрождение высококонтрастных display-serif — консенсус трендов 2026: антиква возвращает ощущение ремесла и наследия после лет доминирования гротеска ([Creative Bloq](https://www.creativebloq.com/design/fonts-typography/breaking-rules-and-bringing-joy-top-typography-trends-for-2026)).
- Выразительные серифы и спокойные тихие сансы идут парой: крупная антиква-хедлайн + мелкий нейтральный гротеск для каптионов и метаданных ([Envato](https://elements.envato.com/learn/font-trends), [TypeType](https://typetype.org/blog/top-10-typography-trends-of-2024/) — modern serifs + neo-grotesques).
- Классические серифы снова добавляют «дорогую» сложность современным макетам; нарративный тип набирает вес вместе с возвратом серифов ([AND Academy](https://www.andacademy.com/resources/blog/graphic-design/typography-trends/)).
- Код журнального разворота: драматический воздух (вертикальные отступы секций 100px+), тонкие чёрные линейки-разделители 1px, drop cap на вводном абзаце ([aesthetic.fyi/editorial](https://aesthetic.fyi/editorial/) — editorial aesthetic codified).
- Вечные редакционные принципы: белое пространство как часть макета, единообразие сетки, ясная иерархия заголовок/дек/тело ([Toast Design](https://www.toastdesign.co.uk/design-resources/editorial-design-principles-2026/)); журнал живёт контрастом масштабов шрифта внутри одной полосы ([AIGA Eye on Design](https://eyeondesign.aiga.org/making-rules-breaking-rules-the-art-of-magazine-typography/)).
- Движение: спокойные reveal'ы — построчный подъём заголовка из маски (translateY 110%→0, easeOutExpo ~0.8s), элементы без рикошетов; сетка после сборки статична (редакционная адаптация трендов [Envato](https://elements.envato.com/learn/font-trends) / паттерн журнальных анонсов).

## Применение в v10

- Кремовая бумага (#F5F0E6) + почти чёрная тушь (#181310) + единственный акцент кирпично-красный (#AC3A23); виньетка бумаги вместо шума (шум ломает сжатие).
- Playfair Display (normal 500–900 + italic) для хедлайна, номеров 01/02/03, дат и подписи; Inter (общий fontSans) для бейджа, кейсов, расписания — контраст антиквы и гротеска-каптиона.
- Иерархия полосы: тонкая линейка мастхеда с бейджем-каптионом → трёхстрочный мега-сериф (Собираем / главный / отдел:) → дек курсивом (папка, контекст и правила) → нумерованные кейсы мелким гротеском с волосяными разделителями.
- Reveal'ы из масок по строкам со сдвигом ~0.4 s между ними; номера кейсов — акцентная антиква-курсив; медленно вращающаяся типографская звёздочка как живая точка композиции.
- End-card как журнальное Contents: дата огромным серифом, время каптионом, газетная двойная линейка, расписание в две колонки волосяными строками, первая строка акцентирована.
