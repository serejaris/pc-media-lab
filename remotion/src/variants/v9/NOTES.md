# V9 «Bento grid»

## Research 2025–2026 (итог)

- Сетка: базовый грид 4 колонки, ячейки шириной 1/2/4 колонки; отступ между ячейками единый, 12–24px — произвольная вариация зазоров разрушает композицию ([Landdding](https://landdding.com/blog/blog-bento-grid-design-guide)).
- Радиусы: скругление одинаковое у всех ячеек, 12–24px; Apple держит ~20px везде — консистентность радиусов коррелирует с воспринимаемой «профессиональностью» интерфейса (+18%) ([Landdding](https://landdding.com/blog/blog-bento-grid-design-guide), [Pixso](https://pixso.net/articles/bento-grids/)).
- Пропорции: зазор ≈ половина внутреннего паддинга ячейки; внутри ячейки 20–30% воздуха; якорная ячейка минимум в 1.5–2 раза крупнее поддерживающих, статистика подаётся как «одна метрика + подпись» ([Brainy](https://brainy.ink/paper/bento-grid-design-guide)).
- Анатомия ячейки фиксирована: метка/визуал сверху → заголовок в середине → деталь снизу; размер ячеек варьируется, внутренний шаблон нет — крупные элементы получают фиксацию внимания в ~2.6 раза дольше ([Landdding](https://landdding.com/blog/blog-bento-grid-design-guide)).
- Движение: staggered-вход ячеек со сдвигом ~50–100ms, каждая — fade 0→1 + scale 0.92→1 на ease-out кривой, вся последовательность собирается быстрее секунды; затем сетка статична ([Motion.dev stagger](https://motion.dev/docs/stagger), [pow.rs easings](https://pow.rs/blog/animation-easings/), паттерн Apple-keynote bento-слайдов).
- Палитра: светлая поверхность + один сочный акцент; лёгкие цветные тинты фона ячейки используются точечно для группировки ключевой информации (пример Notion) ([Landdding](https://landdding.com/blog/blog-bento-grid-design-guide)).

## Применение в v9

- Грид на абсолютах внутри поля 968×968 (внешний паддинг 56, зазор 22, радиус ячеек 28): бейдж-бар → якорь-заголовок → три кейс-колонки 01/02/03 → нижняя пара (акцентная дата-ячейка + счётчик «8»).
- Светлая тема: фон #F4F2EF, ячейки белые с волосяной рамкой, текст #14120F, единственный акцент #EE6018 (занят дата-ячейка полностью, остальное — детали).
- Шрифты: Manrope 500/700/800 (кириллица) — текст; JetBrains Mono 400/500 — бейдж, номера, даты, расписание.
- Появление: spring-вход каждой ячейки opacity+scale 0.93→1+translateY, шаг stagger 7 кадров; end-card перестраивает сетку обратным stagger-выходом и входом when-ячейки, расписания (строки с микростаггером) и подписи; бейдж-бар сохраняется как якорь кадра.
