# V8 «Aurora / Glassmorphism»

- Aurora = 2–3 слоя крупных radial-gradient пятен поверх тёмной базы: цветовая точка ~30% → transparent, тяжёлый blur, oversized контейнер (`inset:-35%`, radius ~45%), drейф translate ±10–12% и поворот −12..18° — [animationpatterns.art, aurora-gradient-sweep](https://animationpatterns.art/animations/aurora-gradient-sweep/).
- Скорости дрейфа из туториала: циклы 9s/11s `ease-in-out infinite alternate` (у нас 30fps → ~270–330f на полцикла, взял медленнее: 600–900f, «majestic» дрейф); нижний слой opacity 0.42, верхний 0.68, `mix-blend-mode: screen`. Палитра референса: cyan #22d3ee, violet #a78bfa, green #34d399.
- Glassmorphism-карточка: `backdrop-filter: blur(10–20px)`, fill rgba(255,255,255,.10–0.25), бордер 1px rgba(255,255,255,.2), мягкая тень; читаемость требует ≥~10% белого фила под текстом — [NN/g glassmorphism](https://www.nngroup.com/articles/glassmorphism/), рецепты 10–25% + blur 12px.
- Josh Comeau про backdrop-filter: за стеклом оставлять спокойный фон, blur>16px делает кашицу, а `saturate()` снимает «мутность» от блюра — [joshwcomeau.com/css/backdrop-filter](https://www.joshwcomeau.com/css/backdrop-filter/).
- Тренд 2025–2026: aurora-градиенты живут в паре с frosted glass («Glassmorphism 2.0» — контролируемые opacity/blur/elevation, сдержанность вместо вспышки) — [colorspalete.com/ui-design-trends-2026](https://colorspalete.com/blog/ui-design-trends-2026), [uxdesign.cc, trends of 2026](https://uxdesign.cc/the-most-popular-experience-design-trends-of-2026-3ca85c8a3e3d).
- Взятые решения: база глубокий индиго (#151038→#0b0a1e), пятна violet #7c3aed / cyan #22d3ee / magenta #db2777 / indigo #4338ca, blur пятен 70–90px, панели blur(14px)+fill .09–.12+border rgba(255,255,255,.22); тёплый золотой акцент для читаемости на холодном фоне; без film grain (шум раздувает битрейт).
